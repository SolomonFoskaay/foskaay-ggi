Ludo multiplayer, fully on-chain

Real players in one session on Arc testnet. Every move runs free inside the Foskaay GGI Midchain, only the connect and the settle are transactions. The sponsor pays those two, never you. This page only displays what the chain says. Single-player Ludo is untouched: this build lives in its own contracts and never shares a session with it.

Open the Foskaay GGI Explorer to verify the session, the seed and the midchain moves.

Press Start for a solo test, or fill the seats and start a real match. Join from a second phone with the session code.
