What Foskaay GGI is

  • One core contract. A single FoskaayGGI (connect a session and pay the fee straight to the destination, settle the result, free randomness). The fee is built in, so connect is one storage write and one transfer, OpenZeppelin only, upgradeable.
  • Cheap by design. Moves, dice, timers, the computer opponent and the points all run inside a session for free. Only the connect and the settle are transactions, so cost is per session, not per action.
  • Game-agnostic. The rail never learns your game. A board, an idle farm or a shared world are all the same to it: participants, opaque state, one settlement.
  • Fully on-chain. Your contract owns the rules and the state. The frontend only displays; there is no local storage and no browser game state.
  • Any player, no wallet setup. Sign in with email, the embedded wallet is created silently, and the player never holds or pays gas.
