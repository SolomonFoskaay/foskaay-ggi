What is Foskaay GGI? It is the open session rail under these demos: a game opens a session on-chain, everything inside is free, and one small settlement closes it. Any game type can plug in through one npm package. GlobalFolkGames is its first user.

These demos exist so a game developer can open their own genre and see it working, instead of taking it on trust.
