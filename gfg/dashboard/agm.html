Earn Competitions (AGM) - staff console

AGM = Automated Game Matcher, the Open/Matched/Locked/Settled match order book for player-to-player earn play. This console manages the platform side only (the P2C backer pool and live orders). Players use the public page at /agm/.

P2C backer pool (ONE shared pool across every game)

P2C = Player vs Computer. When no human is free to take a player's open match, the platform steps in with a computer seat using this single shared pool, so funds are never split thin per game. Pool math: computer win adds (payout minus its stake), computer loss subtracts its stake. A $20 net loss in one GMT day pauses the pool until the day turns over (anti-meltdown).
