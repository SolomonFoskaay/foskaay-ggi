Staff-only: the devnet copy of the automated premium-point payment flow, preserved for testing. The user-facing version runs on mainnet.

Testing on: DEVNET (test) MAINNET (live users)

Devnet USDC is free test money, so a random player must never be able to turn it into real points. Credits on devnet are gated behind this operator token. Without it, you can run the payment UI but the credit step will refuse. Do not share this token.

Devnet uses test USDC (Circle faucet) - nothing real moves. Open the devnet link in a new tab to run a full test payment: fund your embedded wallet with test SOL + USDC, pick a plan, pay, and confirm the points credit server-side.
