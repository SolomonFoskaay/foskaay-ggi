# M6 — Point sources (referral, giveaway, signup, social earn)

The other point sources that feed M4 (lifetime + spendable) but NEVER M3
local and never M4a pure. M3 stays strictly verified gameplay.

- **Signup bonus:** from day 1, joins the platform. Goes to M4c spendable
  (and M4b lifetime).
- **Referral:** invites earn the referrer M4 points when the friend
  joins/plays. Core acquisition, built early.
- **Giveaway:** promotional/lootbox-style surprises (econ-001), feed M4 only.
- **Social earn:** share-linked small earn paths (econ-005).

## Status

`planned` (architecture.json is the source of truth). This folder is the
canonical home for those acquisition modules when they build.
