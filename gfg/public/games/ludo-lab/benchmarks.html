Reading: the ER executes game logic in ~10–20ms per move — the ~1.7s above is only the VRF random-dice callback (matching MagicBlock's own ~2s devnet oracle latency). That means every board move can be validated on-chain while feeling instantaneous, with the dice roll masked by a short animation. The base chain (old web3 path) is ~2.8x slower and the sponsor pays for every roll.
